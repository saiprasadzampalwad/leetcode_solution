## Folder structure

```
leetcode_solution/
├── Array/
│   ├── 1-Two-Sum/
│   │   ├── 1-Two-Sum.<ext>     # solution
│   │   └── README.md           # problem details
│   └── ...
├── Linked-List/
├── Math/
├── Stack/
├── scripts/update_readme.py    # recounts solutions
└── .github/workflows/          # runs the script on every push
```

Folders are named `<problem number>-<Problem-Name>`, so they are easy to find and sort.

## Why this repo

I use LeetCode to practise data structures and algorithms for coding interviews. Solving the same problem in different languages also helps me compare how each one handles memory, recursion and standard libraries.

## Related project
